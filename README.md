# 🏈 Morty Stats — Advanced Fantasy Football Analytics Dashboard

> **A high-octane, multi-season fantasy football analytics platform powered by the Sleeper API.**  
> Delivers deep tactical intelligence across drafts, FAAB bidding, trade market timing, counterfactual lineup simulations, in-season waiver efficiency, and all-time franchise record books.

---

## 🌟 Key Features & Analytic Hubs

### 1. 📖 Record Book & All-Time History (`/`)
* **All-Time Head-to-Head Matrix**: Interactive grid charting lifetime match records, win percentages, and aggregate point differentials between every manager pairing in league history.
* **G.O.A.T. Franchise Index**: Weighted composite scoring model evaluating regular season win rate, total fantasy points scored, championship titles, and playoff appearances.
* **Scoring Records Hub**: Tabbed leaderboards ranking all-time single-game scoring records across Regular Season, Playoffs, and All-Time matchups.
* **All-Time Superlatives**: Lifetime badges honoring highest scorers, biggest blowouts, closest nail-biters, and hardest-luck managers.

### 2. 🏆 Playoff Dynamics & Heartbreak (`/playoffs`)
* **Playoff Brackets & Visualizer**: Interactive championship and consolation bracket views across all league seasons.
* **Winners vs. Chokers Matrix**: Scatter visualization plotting regular season dominance against playoff performance conversion.
* **Benchwarmer Heartbreak Modal**: Deep-dive analysis highlighting the most devastating bench management blunders in playoff history that flipped matchup outcomes.

### 3. 🎯 Draft Intelligence & Steals (`/draft`)
* **Draft Steals & Busts Matrix**: Cartesian scatter plot mapping drafted draft capital vs. actual fantasy points yielded, surfacing league-winning steals and catastrophic busts.
* **Round-by-Round Position Heatmap**: Positional yield heatmap tracking point production across every round and draft slot.
* **Draft Efficiency Index**: Evaluates draft board hit rates, ADP value surplus, and roster longevity.

### 4. 💰 FAAB & Free Agency Efficiency (`/faab` & `/freeagency`)
* **Roster Reliance vs. Win Rate**: Charts the percentage of team points generated by waiver acquisitions against regular season winning percentage.
* **Streamer vs. Stasher Matrix**: Differentiates patient roster developers holding multi-week contributors from high-churn rotational streamers.
* **7-Day Transaction Urgency Heatmap**: Day-of-week claiming density tracking manager waiver wire behavior from Tuesday waivers through Monday kickoffs.
* **Player & Manager Dossier Modals**: Interactive modal profiles detailing acquisition method ($FAAB cost vs. $0 street add), weekly starter PPG, lineup starts, and bench yields.

### 5. 🔄 Trade Analysis & Counterfactual Simulation (`/trades`)
* **Market Timing Matrix**: Scatter matrix mapping player production pre-trade vs. post-trade with dynamic avatar toggles between acquiring and surrendering managers.
* **Counterfactual Lineup Engine**: Re-simulates historical matchup outcomes to determine which trades directly created or cost matchup wins.
* **Interactive Trade Dossier**: Comprehensive asset-by-asset yield breakdown and starter point contributions.

### 6. 👤 League Managers & Composite Index (`/managers`)
* **Manager Composite Index**: Weighted franchise index factoring Drafting (40%), Free Agency (40%), and Trading (20%).
* **Lineup Accuracy & Coaching Efficiency**: Tracks optimal vs. actual lineup point realization across all weeks.
* **Acquisition Production & Accuracy Matrices**: Dual scatter matrices comparing draft vs. waiver point yields and talent evaluation hit rates.
* **Positional & Radar DNA Overlays**: Multi-manager radar comparisons highlighting positional scoring strengths and roster construction traits.

## 🛠️ Tech Stack & Architecture

* **Frontend Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Build Tool & Dev Server**: [Vite](https://vitejs.dev/)
* **Data Visualization**: [Recharts](https://recharts.org/)
* **Styling & Aesthetics**: [Tailwind CSS v4](https://tailwindcss.com/) + Custom Glassmorphism UI tokens
* **Iconography**: [Lucide React](https://lucide.dev/)
* **Testing**: [Vitest](https://vitest.dev/) + [Testing Library](https://testing-library.com/)
* **API**: [Sleeper Fantasy Football REST API](https://docs.sleeper.com/)

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (version 18+ recommended)
* npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/LongSeanSilvr/ffb-stats-dash.git

# Navigate into the project directory
cd ffb-stats-dash

# Install dependencies
npm install
```

### Running Locally

```bash
# Start Vite development server
npm run dev
```

The application will be accessible at `http://localhost:5173`.

### Running Tests & Linting

```bash
# Run unit test suite with Vitest
npm test

# Run single-pass test check
npm test -- --run

# Run ESLint check
npm run lint

# Build production bundle
npm run build
```
